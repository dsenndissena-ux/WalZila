📄 OPTION 1: STATIC HTML VERSION (GitHub Pages - FREE)

This is the SIMPLEST option. Uses the standalone HTML file.

STEP-BY-STEP:

1️⃣  GO TO GITHUB
    → Visit: https://github.com
    → Sign in (or create account)

2️⃣  CREATE NEW REPOSITORY
    → Click "+" → "New repository"
    → Name: wal-zila
    → Set as: Public
    → Click "Create repository"

3️⃣  UPLOAD THESE FILES:
    → Click "uploading an existing file"
    → Upload ONLY these files:
       ✅ index.html
       ✅ README.md
       ✅ .gitignore
    
    → Click "Commit changes"

4️⃣  ENABLE GITHUB PAGES
    → Click "Settings" tab
    → Click "Pages" in left sidebar
    → Source: Select "main" branch
    → Click "Save"

5️⃣  YOUR SITE IS LIVE!
    → Wait 2 minutes
    → Visit: https://YOUR-USERNAME.github.io/wal-zila/
    
✅ DONE! Static version is online.

🐍 OPTION 2: PYTHON FLASK VERSION (Free Hosting Services)

GitHub Pages can't run Python, but these FREE services can:

┌─────────────────────────────────────────────────────────────┐
│ A) PYTHONANYWHERE (EASIEST - RECOMMENDED)                  │
└─────────────────────────────────────────────────────────────┘

1️⃣  SIGN UP
    → Visit: https://www.pythonanywhere.com
    → Click "Start running Python online"
    → Create free account

2️⃣  UPLOAD FILES
    → Go to "Files" tab
    → Click "Upload a file"
    → Upload ALL Python project files:
       • app.py
       • requirements.txt
       • templates/ folder (with index.html inside)
       • static/ folder (with css/ and js/ folders)

3️⃣  INSTALL FLASK
    → Go to "Consoles" tab
    → Click "Bash"
    → Type: pip3 install --user flask
    → Press Enter

4️⃣  CREATE WEB APP
    → Go to "Web" tab
    → Click "Add a new web app"
    → Choose "Flask"
    → Python version: 3.10
    → Path to Flask app: /home/YOUR-USERNAME/app.py
    → Click "Next"

5️⃣  CONFIGURE
    → In Web tab, find "Code" section
    → Source code: /home/YOUR-USERNAME
    → Working directory: /home/YOUR-USERNAME
    → Click "Reload" button

6️⃣  YOUR SITE IS LIVE!
    → URL: https://YOUR-USERNAME.pythonanywhere.com
    
✅ DONE! Python version is online.

┌─────────────────────────────────────────────────────────────┐
│ B) RENDER.COM (AUTO-DEPLOY FROM GITHUB)                    │
└─────────────────────────────────────────────────────────────┘

1️⃣  PUSH TO GITHUB FIRST
    → Create GitHub repository
    → Upload ALL Python files:
       • app.py
       • requirements.txt
       • templates/ folder
       • static/ folder

2️⃣  SIGN UP FOR RENDER
    → Visit: https://render.com
    → Sign up with GitHub account

3️⃣  CREATE WEB SERVICE
    → Dashboard → "New +"
    → Select "Web Service"
    → Connect your GitHub repository

4️⃣  CONFIGURE
    → Name: wal-zila
    → Environment: Python 3
    → Build Command: pip install -r requirements.txt
    → Start Command: python app.py
    → Click "Create Web Service"

5️⃣  YOUR SITE IS LIVE!
    → URL: https://wal-zila.onrender.com
    → First deploy takes 5-10 minutes
    
✅ DONE! Auto-deploys on every GitHub push.

┌─────────────────────────────────────────────────────────────┐
│ C) RAILWAY.APP (SIMPLE & FAST)                             │
└─────────────────────────────────────────────────────────────┘

1️⃣  SIGN UP
    → Visit: https://railway.app
    → Sign up with GitHub

2️⃣  DEPLOY
    → Click "New Project"
    → Select "Deploy from GitHub repo"
    → Choose your repository
    → Railway auto-detects Python

3️⃣  YOUR SITE IS LIVE!
    → Get URL from dashboard
    
✅ DONE! Very fast deployment.

🆘 TROUBLESHOOTING:

Static Site Issues:
   ✗ Videos not playing
   → Videos load when you click thumbnail
   → Check internet connection

   ✗ Site not showing
   → Wait 3 minutes after enabling Pages
   → Repository must be Public
   → File must be named index.html

Python App Issues:
   ✗ "Application failed to start"
   → Check all files uploaded
   → Check requirements.txt exists
   → Check Flask is installed

   ✗ Template not found
   → Verify templates/ folder exists
   → Verify index.html is inside templates/

   ✗ Static files not loading
   → Verify static/ folder structure
   → Check css/ and js/ folders exist
